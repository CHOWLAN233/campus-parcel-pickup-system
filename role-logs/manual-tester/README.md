# Manual Tester

Owners: Manual Tester A; Manual Tester B

主要负责依据合作组需求设计和执行手工测试，覆盖正向、负向、边界、可用性和安全场景，并提交可复现缺陷。日志应关联测试用例和缺陷证据。

主要交付物：

- Manual test cases and execution results
- Defect reports with severity, priority and reproduction steps
- Screenshots/logs and recommendations
- Named evidence for each tester's cases and findings
