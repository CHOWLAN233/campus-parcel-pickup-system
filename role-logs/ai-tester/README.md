# AI Tester

Owner: AI Tester (identity stored in private course records)

主要负责用 AI 辅助生成测试想法或脚本，保存完整 prompts 与 outputs，人工复核并修正测试，再比较 AI 测试与手工测试的覆盖和准确性。AI 输出不能未经审查直接作为结论。

主要交付物：

- Prompts and original AI outputs
- Reviewed and corrected test cases/scripts
- AI-versus-manual comparison and evaluation
- Execution evidence for selected reviewed cases
