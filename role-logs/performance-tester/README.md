# Performance Tester

Owners: Performance Tester A; Performance Tester B

主要负责用 Apache JMeter 对本组应用进行并发测试，定义线程数、ramp-up 和循环次数，测量响应时间、吞吐量与错误率，并分析瓶颈和改进建议。

主要交付物：

- JMeter `.jmx` test plan and safe test data
- Results for average, p90, p95, p99, throughput and error rate
- Performance report with environment, interpretation and bottlenecks
- Named evidence for each tester's scenarios and analysis
