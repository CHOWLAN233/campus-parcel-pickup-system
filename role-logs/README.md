## 更新规则

1. 每项工作由实际执行者本人填写，使用角色编号或 GitHub 用户名，并附 Issue、commit、Pull Request、测试日志或安全截图的相对路径/链接。
2. 任务描述使用 `FR-xx`、`NFR-xx`、`TC-xx` 或 `BUG-xx` 建立追踪关系。
3. 不得在日志中记录密码、session、真实测试账号数据或隐藏预设缺陷答案。
4. “Mistakes and lessons” 必须记录实际问题与学习，不写空泛结论。
5. Test Leader 每周核对所有日志，并在对应记录中填写 initials。
