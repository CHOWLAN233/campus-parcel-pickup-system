# Selenium Tester

Owners: Selenium Tester A; Selenium Tester B

主要负责使用 Selenium 4 和 Page Object Model 自动化关键系统测试，采用显式等待、可复用页面方法，并记录通过/失败、日志和截图。

主要交付物：

- Page Objects and Selenium test scripts
- Execution log, screenshots and result summary
- Traceability from automated tests to manual cases
- Named evidence for each tester's scripts and runs
