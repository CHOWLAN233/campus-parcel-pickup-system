# Test Leader

Owner: Test Leader (identity stored in private course records)

主要负责测试计划与日程、需求追踪矩阵、缺陷跟踪、组员日志核验、测试总结、发布建议和小组演示。日志应体现协调决策、覆盖率检查、风险与阻塞处理，而不只是会议次数。

主要交付物：

- Test plan and schedule
- Requirements-to-tests-to-defects traceability matrix
- Test summary and release recommendation
- Group presentation and verified weekly logbooks
